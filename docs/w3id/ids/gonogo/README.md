# /gonogo/

Permanent identifiers for GoNoGo, an open ontology for patent license clearance.

`https://w3id.org/gonogo/ontology#` is the ontology namespace. `https://w3id.org/gonogo/ontology` redirects to
the generated documentation, or to the Turtle file for clients that ask for `text/turtle`.

Documentation: <https://gonogo-livid.vercel.app/ontology/index.html>
Source: <https://github.com/abh2050/gonogo>
